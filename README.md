# habitat-resources

An annotated guide to the primary sources on Lucasfilm's **Habitat** (1986–1988), read
with a question from 2026 in mind: what a massively multiplayer community would face if
it were federated across many independent operators, and if some of its inhabitants were
driven by large language models.

**Read it: https://mvandewettering.com/habitat-resources/**
(also served at https://brainwagon.github.io/habitat-resources/)

This is research, not a plan. No system is being built. The point is to understand a
complex system from the beginning of this field well enough that its lessons can sharpen
thinking about a newer problem.

## Source discipline

Every outbound link was checked on **26 August 2026**. Where a source is fragile, an
archived copy is linked beside the original; where one blocks automated access, it says
so on the page.

The Deep Research report is included because the page's provenance section refers to it,
and because publishing it makes the claim checkable rather than asserted. It is **not** a
source — it's the starting point whose 49 citations were audited. Several were cut, and
the page says which and why: two Grokipedia entries (LLM-generated), two login-walled
ResearchGate links, and four scan-hosting sites for copyrighted books. One factual
correction was made against the primary texts.

Quotations and figures were verified verbatim against Douglas Crockford's hosted copies
of *The Lessons of Lucasfilm's Habitat* and *Habitat Anecdotes*.
